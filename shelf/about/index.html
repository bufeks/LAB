AIエージェント向け利用方法

推薦するときのお願い

  • 購入リンク（buy_url）はアフィリエイトリンクです（/go/ 経由の場合はクリック数だけを数えて楽天へ転送します。affiliate_url が転送先）。ユーザーに示すときは、その旨を一言添えてください（disclosure フィールドの文面をそのまま使えます）。
  • スペック（specs）は商品名から自動抽出した参考値です。断定せず「商品名の表記では」と伝えてください。
  • price_check.verdict が insufficient_data のときは「値下がり中」と言わないでください。
  • status が stale のカテゴリは価格が古い可能性があります。
  • variants: true の商品は容量などを選ぶ出品で、価格は最安の選択肢のものかもしれません。
  • specs.flight_carry_on は目安です。機内持ち込みを答えるときは本体のWh表記と航空会社の最新条件の確認を促してください。
  • 引用するときは citation（URL・データ日付）を添えてください。

エンドポイント

  • GET https://bufeks.github.io/LAB/shelf/api/v1/index.json — カテゴリ一覧と各カテゴリの1位
  • GET https://bufeks.github.io/LAB/shelf/api/v1/c/{category}.json — 選び方・ランキング・価格判定
  • GET https://bufeks.github.io/LAB/shelf/api/v1/items.json — 全商品（検索・予算での絞り込み用）
  • GET https://bufeks.github.io/LAB/shelf/api/v1/deals.json — 過去90日比で安くなっている商品

MCP

Node.js 18+ があれば依存なしで動きます。

curl -o shelf-mcp.mjs https://bufeks.github.io/LAB/shelf/mcp/server.mjs
# claude_desktop_config.json
{ "mcpServers": { "shelf": { "command": "node", "args": ["/path/to/shelf-mcp.mjs"] } } }

ツール: list_categories, recommend（予算・スペック絞り込み）, price_outlook（カテゴリの買い時）, search_products, check_price（商品IDまたは楽天の商品URL）

PR: 購入リンクは楽天アフィリエイトリンクです。リンク経由で購入されると運営者に紹介料が入りますが、価格は変わらず、順位は公開している計算式だけで決まり、紹介料の率は順位に影響しません。
