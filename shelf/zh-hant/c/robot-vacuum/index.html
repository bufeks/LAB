怎麼選

地圖建構
用 LiDAR（雷射）或鏡頭建立房間地圖的機種，行走效率高，能設定禁區或按房間清掃。
機身高度
想清掃沙發或床底下，請比較家具下方的空隙與機身高度。
自動集塵
由充電座把灰塵吸走的機種，幾週才需要倒一次垃圾。底座較大，且需要集塵袋的費用。
拖地
以木地板為主的家很方便。家裡有地毯的話，請確認是否有抬起拖布的功能。
耗材
請確認刷子、濾網、集塵袋的更換費用與是否容易買到。

注意事項

  • 可能會捲入地上的電線或小東西，需要養成使用前整理地面的習慣。
  • 需連動 App 的機種，可能因廠商終止服務而無法使用部分功能。
  • 在日本以外使用: 在海外使用前，請確認充電座的變壓器（電源轉接器）是否支援 100–240V 輸入；只支援 100V 的話，不可在 220–240V 電源使用。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
