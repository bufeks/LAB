怎麼選

每公斤價格
有 5kg、10kg、5kg×2 袋等不同容量，請用總重量換算單價比較。運費另計的商品請加上運費重新計算。
產年・碾米日
「令和◯年產」越新越接近新米。碾米後風味會逐漸流失，選碾米日期較新的、少量多次購買比較好吃。
單一原料米與混合米
「單一原料米」是產地、品種、產年都相同的米。混合米價格較便宜，口味多半不如品牌米。
免洗米
不用洗就能煮，不會產生洗米水，省工又省水。因碾米時多去除了一部分，同樣重量通常稍貴。
保存
避開高溫潮濕，放在密封容器保存。夏天適合放冰箱蔬果室。以約一個月能吃完的量為準。

注意事項

  • 「5kg×2」和「10kg」份量相同。分袋包裝比較好保存。
  • 定期配送與故鄉稅回禮品屬於另一種比較（這裡只比較一般購買）。
  • 在日本以外使用: 將米帶入台灣或其他國家可能受到限制，請事先確認當地的檢疫與入境規定。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
