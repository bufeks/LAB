怎麼選

每顆價格
有 4 顆、20 顆、40 顆等不同數量，請用顆數換算比較。
建議使用期限
從製造起可保存期間的參考。作為儲備用請選期限較長的，並在期限內輪替使用。
用途
耗電量大的裝置（遊戲手把、相機閃光燈等）電池消耗快。經常更換的話，長期來看充電電池可能比較便宜。
漏液
用完的電池，以及長時間不用的裝置裡的電池，先取出來可以避免漏液造成故障。

注意事項

  • 不要把新舊電池、不同種類的電池混用。
  • 丟棄時用膠帶把電極絕緣，並依當地的垃圾分類規定處理。
  • 在日本以外使用: 在任何地方都能用。鹼性乾電池一般可放在行李中搭機，請依所搭航空公司的規定。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
