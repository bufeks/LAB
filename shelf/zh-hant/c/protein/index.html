怎麼選

每公斤價格
有 1kg、3kg、1kg×2 等不同容量，請用總重量換算比較。容量越大通常越划算。
種類
乳清來自牛奶，吸收快。WPI 是減少乳糖、精製度高的乳清，適合容易腸胃不適（拉肚子）的人。大豆蛋白來自黃豆，吸收較慢。
蛋白質含量
同樣 1kg，各產品的蛋白質量不同。用每份的蛋白質量與價格，算出每 1 公克蛋白質的費用來比較最公平。
甜味劑・添加物
也有適合想避開人工甜味劑者的無添加、原味款。口味較差，但也容易用於料理。

注意事項

  • 運動員有誤含禁藥檢測成分的風險，請確認是否有第三方認證（如 Informed Choice）。
  • 有慢性病或需限制蛋白質攝取量的人，請先諮詢醫師。
  • 在日本以外使用: 將營養補充品或含乳製品的食品帶入台灣或其他國家可能受到限制，請事先確認當地的檢疫與入境規定。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
