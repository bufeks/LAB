怎麼選

輸出（W）
iPhone 快充需要 20W 以上。筆電請選與原廠變壓器相同或更高的瓦數（例如 65W、96W）。
多孔功率分配
「總計 65W」在同時充兩台時可能分成 45W+20W。要同時幫電腦和手機充電，請確認分配表。
PPS
Galaxy 等手機的「超級快充」需要支援 USB PD PPS 的充電器。
GaN
採用氮化鎵的充電器在相同輸出下更小更輕，常帶出門的話值得優先考慮。
傳輸線
超過 60W 的供電需要支援 5A（含 e-marker 晶片）的 USB-C 線。線只支援 3A 的話，充電器瓦數再高也只能到 60W。

注意事項

  • 沒有 PSE 標章的充電器不得在日本販售，請確認標示。
  • 只比較總輸出，可能忽略單孔最大輸出不足。
  • 在日本以外使用: 在日本販售的 USB-C 充電器大多支援 100–240V 輸入，搭配轉接頭可在海外使用（日本為 A 型雙扁腳插頭）。請確認標籤上有「100-240V」。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
