怎麼選

風量
一般機型約 1.3–1.5m³/分鐘，大風量機型約 2m³/分鐘。風量越大，吹乾時間越短，吹熱風的時間也越少。
溫度切換
風太熱會傷頭髮和頭皮。有低溫模式或冷熱切換，可在吹整收尾或夏天時切換使用。
重量・造型
每天都要用，拿在手上的重量與平衡大大影響滿意度。要收納的話選可折疊式。
負離子類功能
nanoe（奈米水離子）等是各廠商的獨家功能，效果感受因人而異。先比較風量與溫度控制，附加功能依喜好選擇。
消耗功率
多為 1200W 級，和其他家電同時使用可能會跳電。

注意事項

  • 進風口積灰塵會讓風量下降，也可能造成過熱，請定期清潔。
  • 把電線纏繞在機身上收納，容易造成斷線。
  • 在日本以外使用: 依日本 100V 電壓設計，原廠只保證在日本使用。台灣的 110V 比額定電壓高，可能過熱或故障；220–240V 電源絕對不可使用。

排行規則

每個類別依評價數從樂天取得最多 60 項商品，依排除字詞、價格區間與最低評價數篩選。不同店家販售的同一商品（型號相同，或規格相同且名稱幾乎一致）合併為評分最高的一項，其他店家的價格保留在 other_offers。其餘依「貝氏平均評分」排序。

score = (C × m + n × r) / (C + n) … r = 該商品平均評分，n = 評價數，m = 所有候選商品的平均評分，C = 50

讓有數千則評價的 4.4★ 排在只有幾則評價的 5★ 之前。評價越少，評分越被拉向整體平均。

規格是從商品名稱機械式擷取的參考值，可能有誤。購買前請在商品頁面確認。
