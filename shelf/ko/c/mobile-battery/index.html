고르는 법

용량 (mAh)
전압 변환 손실 때문에 표시 용량 중 실제로 스마트폰에 들어가는 것은 약 60~70%. 10,000mAh로 일반 스마트폰을 약 1.5~2회 충전할 수 있다.
출력 (W)
iPhone 고속 충전은 USB PD 20W 이상. 노트북은 정품 어댑터에 가까운 와트(45~65W 이상)가 필요하다.
무게
10,000mAh급은 약 180~250g, 20,000mAh급은 약 300~450g. 들고 다닐 거라면 용량보다 무게로 먼저 좁힌다.
PSE 마크
2019년 2월부터 PSE 마크가 없는 보조배터리는 일본에서 판매할 수 없다(전기용품안전법). 표기가 없는 상품은 피한다.
비행기
위탁 수하물 불가, 기내 반입만 가능. 일반 기준은 100Wh 이하 승인 불필요, 100Wh 초과 160Wh 이하는 항공사 승인 필요(보통 2개까지), 160Wh 초과는 반입 불가. 2025년 이후 기내 사용·충전을 금지하거나 개수를 제한하는 항공사가 늘었고, 일본 국내선에서는 선반이 아니라 몸 가까이에 두도록 요구한다. 본체의 Wh 표기를 확인하고(20,000mAh는 약 74Wh, 27,000mAh급은 100Wh 전후라 확인 필요) 이용하는 항공사의 최신 규정을 확인한다.

주의할 점

  • 시세보다 지나치게 싼 대용량 제품은 용량 표기가 부풀려져 있을 수 있다.
  • 부풀거나 뜨거워지거나 냄새가 나면 사용을 멈추고 지자체나 JBRC 협력점 수거함에 낸다(일반 쓰레기로 버리지 않는다).
  • 일본 밖에서 사용할 때: 어디서나 쓸 수 있다(USB). 비행기로 가져갈 때는 반드시 기내 반입하고, 본체의 Wh 표기를 확인한다.

랭킹 산정 방법

카테고리마다 라쿠텐에서 리뷰 수 순으로 최대 60개를 가져와 제외어·가격대·최소 리뷰 수로 거른다. 여러 상점이 파는 같은 상품(모델명이 같거나, 사양이 같고 상품명이 거의 같은 것)은 평점이 가장 높은 하나로 합치고, 다른 상점 가격은 other_offers에 남긴다. 나머지를 “베이즈 평균 평점”으로 정렬한다.

score = (C × m + n × r) / (C + n) … r = 해당 상품 평균 평점, n = 리뷰 수, m = 전체 후보의 평균 평점, C = 50

리뷰 몇 건의 ★5보다 리뷰 수천 건의 ★4.4를 위에 두기 위해서다. 리뷰가 적을수록 평점이 전체 평균 쪽으로 당겨진다.
