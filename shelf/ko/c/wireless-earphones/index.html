노이즈 캔슬링
전철, 비행기, 카페에서 효과가 크다. 성능 차이가 커서 리뷰 수가 많은 모델이 무난하다.
코덱
iPhone은 LDAC/aptX를 지원하지 않아 AAC까지다. LDAC/aptX를 지원하는 안드로이드 폰이라면 같은 코덱을 지원하는 이어폰으로 음질이 좋아진다.
멀티포인트
두 기기에 동시에 연결해, PC로 회의하다가 스마트폰 전화를 재연결 없이 받을 수 있다.
방수
IPX4 이상이면 땀과 가벼운 비를 견딘다. 운동용이면 IPX5 이상.
재생 시간
“최대 N시간”은 케이스 충전을 포함한 수치인 경우가 많다. 이어폰 단독 연속 재생 시간을 따로 확인한다.

  • 일본 밖에서 사용할 때: 어디서나 쓸 수 있다. USB로 충전한다.

랭킹 산정 방법

카테고리마다 라쿠텐에서 리뷰 수 순으로 최대 60개를 가져와 제외어·가격대·최소 리뷰 수로 거른다. 여러 상점이 파는 같은 상품(모델명이 같거나, 사양이 같고 상품명이 거의 같은 것)은 평점이 가장 높은 하나로 합치고, 다른 상점 가격은 other_offers에 남긴다. 나머지를 “베이즈 평균 평점”으로 정렬한다.

score = (C × m + n × r) / (C + n) … r = 해당 상품 평균 평점, n = 리뷰 수, m = 전체 후보의 평균 평점, C = 50

리뷰 몇 건의 ★5보다 리뷰 수천 건의 ★4.4를 위에 두기 위해서다. 리뷰가 적을수록 평점이 전체 평균 쪽으로 당겨진다.
