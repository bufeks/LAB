고르는 법

풍량
일반 모델은 1.3~1.5m³/분 안팎, 대풍량 모델은 2m³/분 안팎. 풍량이 클수록 건조 시간이 짧아지고 열을 쐬는 시간도 줄어든다.
온도 전환
너무 뜨거운 바람은 머리카락과 두피에 부담이 된다. 저온 모드나 온풍·냉풍 전환이 있으면 마무리나 여름철에 나눠 쓸 수 있다.
무게·형태
매일 쓰는 것이라 손에 들었을 때의 무게와 균형이 만족도를 좌우한다. 수납을 생각하면 접이식.
이온 계열 기능
나노이 등은 제조사별 독자 기능으로, 효과를 느끼는 정도는 사람마다 다르다. 풍량과 온도 관리를 먼저 비교하고, 부가 기능은 취향으로 고른다.
소비 전력
1200W급이 많아 다른 가전과 함께 쓰면 차단기가 내려갈 수 있다.

랭킹 산정 방법

카테고리마다 라쿠텐에서 리뷰 수 순으로 최대 60개를 가져와 제외어·가격대·최소 리뷰 수로 거른다. 여러 상점이 파는 같은 상품(모델명이 같거나, 사양이 같고 상품명이 거의 같은 것)은 평점이 가장 높은 하나로 합치고, 다른 상점 가격은 other_offers에 남긴다. 나머지를 “베이즈 평균 평점”으로 정렬한다.

score = (C × m + n × r) / (C + n) … r = 해당 상품 평균 평점, n = 리뷰 수, m = 전체 후보의 평균 평점, C = 50

리뷰 몇 건의 ★5보다 리뷰 수천 건의 ★4.4를 위에 두기 위해서다. 리뷰가 적을수록 평점이 전체 평균 쪽으로 당겨진다.
