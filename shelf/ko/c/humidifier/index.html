고르는 법

가열식 (스팀)
물을 끓이므로 세균이 잘 나오지 않고 가습력도 높다. 소비 전력이 수백 W로 크고, 분출구가 뜨거운 제품도 있다.
기화식
젖은 필터에 바람을 쐬는 방식으로 전력 소모가 적고 조용하다. 가습력은 실내 온도·습도에 좌우되며 필터를 정기적으로 세척·교체해야 한다.
초음파식
싸고 작고 조용하다. 물을 그대로 안개로 만들기 때문에 물통을 관리하지 않으면 세균을 뿌린다. 수돗물 미네랄 때문에 흰 가루가 생길 수 있다.
복합식
기화식이나 초음파식에 히터를 더해 가습력과 전력 소모의 균형을 잡는다. 가격은 높은 편.
적용 면적
“목조 일본식 방 ○조 / 조립식 서양식 방 ○조” 두 가지가 적혀 있고, 목조 쪽 숫자가 작다. 집에 맞는 쪽 숫자로 비교한다.

주의할 점

  • 교체 필터 가격과 구하기 쉬운지(유지비)를 먼저 확인한다.
  • 물통 입구가 좁으면 세척이 어려워 위생 차이로 이어진다.
  • 일본 밖에서 사용할 때: 일본의 100V 전용 설계이며 제조사는 일본 내 사용만 지원한다. 한국의 220V에서는 절대 쓰지 말 것(변압기 없이는 고장·화재 위험).

랭킹 산정 방법

카테고리마다 라쿠텐에서 리뷰 수 순으로 최대 60개를 가져와 제외어·가격대·최소 리뷰 수로 거른다. 여러 상점이 파는 같은 상품(모델명이 같거나, 사양이 같고 상품명이 거의 같은 것)은 평점이 가장 높은 하나로 합치고, 다른 상점 가격은 other_offers에 남긴다. 나머지를 “베이즈 평균 평점”으로 정렬한다.

score = (C × m + n × r) / (C + n) … r = 해당 상품 평균 평점, n = 리뷰 수, m = 전체 후보의 평균 평점, C = 50

리뷰 몇 건의 ★5보다 리뷰 수천 건의 ★4.4를 위에 두기 위해서다. 리뷰가 적을수록 평점이 전체 평균 쪽으로 당겨진다.
