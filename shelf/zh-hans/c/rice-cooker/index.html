怎么选

容量
如果经常只煮最大容量的一半左右，选小一档的更不容易煮得不均匀。
加热方式
微电脑式用底部加热盘加热，价格便宜。IH 加热整个内胆，火力强。压力 IH 加压高温煮饭，口感更软糯。
内胆
厚釜或土锅、铁、铜等材质会影响蓄热性。价格差异大多来自这里。
清洁
每次要洗的部件（内盖、蒸汽口）越少，越容易坚持。
保温
长时间保温容易让米饭发黄、变干。如果习惯冷冻保存，比起保温性能，更应重视煮出来的口感。

注意事项

  • 内胆涂层损坏后需要付费更换，请事先看看替换内胆的价格。
  • 在日本以外使用: 按日本 100V 电压设计，厂家只支持在日本使用，绝对不要在 220–240V 电源上使用。部分厂家另有面向海外的型号。

排行规则

每个品类按评价数量从乐天获取最多 60 件商品，按排除词、价格区间和最低评价数筛选。不同店铺出售的同一商品（型号相同，或规格相同且商品名几乎一致）合并为评分最高的一件，其他店铺的价格保留在 other_offers 中。其余按“贝叶斯平均评分”排序。

score = (C × m + n × r) / (C + n) … r = 该商品平均评分，n = 评价数，m = 所有候选商品的平均评分，C = 50

让有数千条评价的 4.4★ 排在只有几条评价的 5★ 之前。评价越少，评分越被拉向整体平均。

规格是从商品名中机械提取的参考值，可能有误。购买前请在商品页面确认。
