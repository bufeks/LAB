怎么选

主动降噪
在电车、飞机和咖啡馆里效果最明显。不同型号的降噪强度差别很大，选评价数多的型号更稳妥。
编码格式
iPhone 不支持 LDAC/aptX，最高为 AAC。支持 LDAC/aptX 的安卓手机，搭配支持相同编码的耳机音质更好。
多点连接
可同时连接两台设备，例如在电脑上开会时直接接听手机来电，无需重新配对。
防水
IPX4 以上可防汗水和小雨，运动用建议 IPX5 以上。
续航
“最长 N 小时”通常包含充电盒的补充电量，请另外确认耳机单次连续播放时间。

注意事项

  • 佩戴感和隔音效果很大程度取决于耳朵形状，请确认是否附带多种尺寸的耳塞。
  • 在日本以外使用: 在任何地方都能用，通过 USB 充电。

排行规则

每个品类按评价数量从乐天获取最多 60 件商品，按排除词、价格区间和最低评价数筛选。不同店铺出售的同一商品（型号相同，或规格相同且商品名几乎一致）合并为评分最高的一件，其他店铺的价格保留在 other_offers 中。其余按“贝叶斯平均评分”排序。

score = (C × m + n × r) / (C + n) … r = 该商品平均评分，n = 评价数，m = 所有候选商品的平均评分，C = 50

让有数千条评价的 4.4★ 排在只有几条评价的 5★ 之前。评价越少，评分越被拉向整体平均。

规格是从商品名中机械提取的参考值，可能有误。购买前请在商品页面确认。
