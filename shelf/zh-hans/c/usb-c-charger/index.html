怎么选

输出（W）
iPhone 快充需要 20W 以上。笔记本电脑请选与原装适配器相同或更高的功率（例如 65W、96W）。
多口功率分配
“总计 65W”在同时充两台设备时可能分成 45W+20W。要同时给电脑和手机充电，请确认分配表。
PPS
Galaxy 等手机的“超级快充”需要支持 USB PD PPS 的充电器。
GaN
采用氮化镓的充电器在相同输出下更小更轻，经常携带的话值得优先考虑。
数据线
超过 60W 的供电需要支持 5A（带 e-marker 芯片）的 USB-C 线。如果线只支持 3A，即使充电器功率高也只能到 60W。

注意事项

  • 没有 PSE 标志的充电器不得在日本销售，请确认标注。
  • 只比较总输出，可能忽略单个接口的最大输出不够。
  • 在日本以外使用: 在日本销售的 USB-C 充电器大多支持 100–240V 输入，配合转换插头可在海外使用（日本为 A 型两扁脚插头）。请确认标签上有“100-240V”。

score = (C × m + n × r) / (C + n) … r = 该商品平均评分，n = 评价数，m = 所有候选商品的平均评分，C = 50

让有数千条评价的 4.4★ 排在只有几条评价的 5★ 之前。评价越少，评分越被拉向整体平均。
