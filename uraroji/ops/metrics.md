## 2. 目標

| 時期 | 無料読者 | 有料読者 | 開封率 | 見るべきこと |

| 創刊時（11/5） | 100 | — | — | 知り合い経由で100人 |

## 3. 有料化を始める基準（どれか1つを満たしたら）

- 無料読者が **1,000人** を超えた
- 無料読者が **500人** 以上で、開封率が **50%** 以上
- 読者から「お金を払いたい」「もっと読みたい」という声が5件以上来た

始めるときは Founding Member（$150/年）を目立たせ、最初の2週間だけ年額を割引にする。

## 4. 月次レビュー（月末の日曜、30分）

1. **一番読まれた号と、一番読まれなかった号**はどれか。ジャンル・件名の型・切り口の違いは何か
2. **新規読者がどこから来たか**（Notes、推薦、X、Reddit、検索）。一番効いた経路に翌月の時間を寄せる
3. **返信やコメントで来たリクエスト**を `editorial/ideas.md` に移す
4. 翌月の `editorial/calendar.md` を並べ替える：Long Read 1本、Context 1本、Deep Cut 2〜3本
5. 週の作業時間が4時間を超えていたら、何を自動化・省略するか決める

## 5. 危険信号

| 兆候 | 対処 |
| --- | --- |
| 開封率が3週続けて35%を切る | 件名の型を変える。配信時刻を試す |
| 解約・配信停止が1号で2%を超える | その号のテーマと長さを見直す。長すぎないか |
| 新規読者が1か月ほぼゼロ | Notes の頻度と、相互推薦の相手を増やす |
| 自分が書くのを楽しめていない | ジャンルを自分の好きなほうへ寄せる。熱量は読者に伝わる |
