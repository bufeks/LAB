# 創刊前にやること（一度だけ）

創刊予定日：**2026-11-05（木）**。それまでに4本のストックを持って創刊する。

## 1. 名前・アカウントの確保（〜10/3）
- [ ] `uraroji.substack.com` が取れるか確認して登録
- [ ] ドメイン `uraroji.com`（取れなければ `.jp` や `uraroji.co`）。Substack の有料機能でカスタムドメインを設定
- [ ] SNS のハンドル：X、Bluesky、Instagram、Threads、Letterboxd、Reddit（すべて `uraroji` でそろえる）
- [ ] Google で「Uraroji」を検索し、紛らわしい店やブランドがないか確認

## 2. Substack の設定（〜10/10）
- [ ] **Settings → Basics**：名前、タグライン、短い説明（`brand/about.md` の文面）
- [ ] **ロゴとヘッダー**：自作。夜の路地、裸電球、古本の紙の色。アイキャッチの統一テンプレート（1200×630）も作る
- [ ] **About ページ**：`brand/about.md` を貼る
- [ ] **Welcome email**：`brand/about.md` のウェルカムメール
- [ ] **Sections（セクション）**：`The Deep Cut` / `Long Reads` / `Field Notes` を作る。通知は読者が選べるようにする
- [ ] **言語とタイムゾーン**：English、Asia/Tokyo
- [ ] **Recommendations**：近いテーマのニュースレターを3〜5本推薦に入れる（相互推薦の土台）
- [ ] **有料化はまだしない**。Stripe の接続だけ先に済ませておく（審査に時間がかかることがある）

## 3. 自動化の準備（〜10/5）
- [ ] Google ドライブに「Uraroji Drafts」フォルダがなくても、ルーティンの初回で自動的に作られる
- [ ] 下書きルーティンの初回（10/5 月）の通知メールが Gmail に届くか確認
- [ ] 届かない、または中身がおかしいときは `automation/draft-routine.md` §4 を見る

## 4. ストックづくり（10/5〜11/4）
- [ ] ルーティンを毎週1回＋手動で追加実行して、01〜04号の下書きを先に作る
- [ ] 01号（つげ義春）はとくに時間をかける。Start here に置く、看板の号
- [ ] 4本とも `[YOUR TAKE]` を書き、アイキャッチを作り、チェックリストを通す
