# 公開前チェックリスト

Substack で予約する前に、上から順に確かめる。1つでも外れたら予約しない。

## 中身
- [ ] `[要確認]` と `[YOUR TAKE]` の文字が本文に1つも残っていない
- [ ] 作り手の目での指摘（The maker's eye）が具体的に書かれている
- [ ] 個人的な一文（A local's note）が自分の実体験になっている
- [ ] 年、作者名、掲載誌、英訳の出版社を出典で確かめた
- [ ] 「英語で読む・観る方法」のリンクが生きている。英訳の収録巻が合っている
- [ ] 過去号へのリンクを1つ以上入れた（2号目以降）

## 表記
- [ ] 人名は「名・姓」、作品名は英訳名＋原題（初出のみ）
- [ ] 日本語の単語はイタリックで5語まで
- [ ] 900〜1,300語（Long Read は3,000〜5,000語）

## 画像と権利
- [ ] 作品の画像は1〜3点。出典を明記した
- [ ] ページ全体・連続したコマのスキャンがない
- [ ] アイキャッチは自作で、統一テンプレートを使った
- [ ] アフィリエイトリンクがあれば、末尾に開示の一文を入れた

## Substack の設定
- [ ] タイトル、サブタイトル、号数ラベル
- [ ] セクションは `The Deep Cut`（または該当のもの）
- [ ] SEO 設定：検索用タイトルと説明文（下書きの案を使う）
- [ ] 配信対象：Everyone（Long Read を有料にするなら Paid subscribers only＋paywall の位置）
- [ ] プレビューのメールを自分に送り、スマホで読んで崩れがない
- [ ] **予約：木曜 22:00 JST**

## 配信後
- [ ] `editorial/calendar.md` の状態を「配信済」に
- [ ] About の Start here を差し替えるべき号かどうか判断した
