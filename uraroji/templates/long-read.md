# Long Read — 月1回の長編の型

3,000〜5,000語。有料化したら、冒頭の約300語までを無料で見せ、そこから先を有料にする（Substack の paywall ブロック）。

## 構成

1. **問い（件名にする）**：*What Was* Garo*, and Why Does Japanese Comics Still Orbit It?*
2. **冒頭のシーン（300語）**：具体的な場面から始める。人物、年、場所、モノ（1冊の雑誌、1枚のポスター）
3. **――ここに paywall――**
4. **章立て（3〜5章、各章に見出し）**：時代順か論点順。各章の最後に次の章への引きを入れる
5. **The maker's eye**：作り手の目で分析する章を1つ必ず入れる
6. **現在とのつながり**：今の日本の作品や、海外の作り手への影響
7. **読むためのリスト**：英語で手に入る作品と、そうでない作品を分けて
8. **出典一覧**：本、記事、インタビュー（Long Read は出典を必ず載せる）

## 準備
- 公開の3週間前にテーマを決め、ルーティンに下書きさせる（カレンダーに入れておけば自動）
- 自分で資料を1〜2冊は読む。ここは AI まかせにしない
- 図解やタイムラインを自作すると、有料の価値が上がる
