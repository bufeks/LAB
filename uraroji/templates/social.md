# SNS の型

配信の翌日（金曜）に出す。ルーティンが毎号この型で文面を作ります。

## Substack Notes（最重要。Substack 内の成長の中心）
- **配信当日**：本文から一番強い1段落を抜き出し、記事リンクを添える
- **週に2〜3回**：記事と関係ない短い観察（「今日神保町で見つけたもの」＋写真1枚）。宣伝だけにしない
- 近いテーマの書き手の Notes に、中身のあるコメントをする（週5件）

## X / Bluesky（スレッド形式）
```
1/ 表紙画像＋フック1文（件名を言い換える）
2/ 作品の一言紹介（年・作者・媒体）
3/ 日本で特別な理由を1点
4/ 作り手の目での指摘を1点
5/ 英語で読める・観られる場所
6/ 全文はこちら → [リンク]
```

## Instagram（カルーセル5枚）
1. タイトル画像（自作。統一デザイン）
2. 作品の基本情報
3. 日本での文脈を1点
4. 作り手の目での指摘（図解を自作）
5. 「全文は Substack で。プロフィールのリンクから」

画像は自作の図解を中心にする。作品の画像は引用の範囲（1点、出典つき）。

## Reddit（月1〜2回まで）
- r/manga、r/TrueFilm、r/japaneseculture などのルールを必ず確認
- リンクを貼るだけの投稿はしない。本文に価値のある要約を書き、最後に「詳しくはここに書いた」と添える
- 反応が良かった話題は、次の Context 号の候補にする

## ハッシュタグ・キーワード（使いすぎない）
`#manga #alternativemanga #Garo #japanesefilm #ATG #showa #japaneseculture`
