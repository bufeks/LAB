# BREAK TO CREATE. — 自身の再構築 (Ver.2)

> DESTROY THE OLD SELF. DISCOVER THE NEW YOU.

生成された自分の胸像に触れ、壊し、塗り替えることで殻を破り、新たな自分の形を見出す体験。

公開URL: **https://bufeks.github.io/LAB/v2/**
（Ver.1「顔にペイント」はそのまま https://bufeks.github.io/LAB/ にあります）

## Ver.1 との違い

Ver.1 は鏡像にリアルタイムで描くものでした。Ver.2 は**対象が静止した胸像**です。
これは見た目の違いではなく構造の違いで、体験が3幕になります。

| | Ver.1 | Ver.2 |
| --- | --- | --- |
| 対象 | 動いている自分の顔 | 撮影して生成した自分の胸像 |
| 主眼 | 顔に貼りつく塗り | 壊す → 塗り替える → 立ち上がる |
| 中心技術 | 顔ローカル座標へのアンカリング | 変位フィールドによる変形 + インクの物理 |
| 出力 | スクリーンショット | OLD SELF / NEW SELF の対比とプリント |

胸像が静止しているので、Ver.1 で苦労した「塗りを顔に追従させる」問題自体が消えます。
かわりに、変形とインクの垂れという Ver.1 にはできなかった表現が使えるようになりました。

## 体験の流れ

1. **GENERATE** — カメラに顔を合わせると自動でシャッターが切れ（`いま撮る` / Space でも可）、
   その1フレームから胸像が生成される。
2. **BREAK** — 手のジェスチャーで壊し、塗り替える。
3. **NEW SELF** — OLD SELF と並べて提示し、その場でプリント（PNG保存）。

## 操作

親指と人差し指を**つまむ**と、選択中のツールが働きます。画面左の色と下のツールも
つまんで選べます（マウスでも同じ）。

| ツール | 動き |
| --- | --- |
| **BREAK** 歪ませる | つまんで動かすと、粘土のように表面が引きずられる。乗っているインクも一緒に伸びる |
| **INK** ぶつける | つまむとインク玉が当たる。手の速度の向きに飛沫が伸び、そこから数本垂れる |
| **PAINT** 塗る | つまんで動かすとストローク。時々飛沫と垂れが出る |
| **POUR** ぶちまける | つまむとバケツ1杯分。カーテン状に何本も流れ落ちる |

キーボード: `1`–`6` 色 / `b` `i` `p` `o` ツール / `[` `]` 太さ / `z` 戻す / `r` 全部戻す /
`Enter` 完成 / `h` UI非表示 / `f` フルスクリーン。完成後は `s` 保存 / `Enter` もう一度。

## 仕組み

3枚のレイヤーを WebGL2 のフラグメントシェーダで1回合成しています。

```
uv' = uv + displacement(uv)      ← 変位フィールド (RG8, 192x108)
色  = portrait(uv') に ink(uv') を重ねる
```

**胸像の生成** (`src/portrait.js`)
1フレームを取り込み、ImageSegmenter（selfie_segmenter）で人物を切り抜き、
グレースケール化・コントラスト強調して紙の上に置く。ぼかし差分によるエッジ抽出を
乗算で重ね、写真ではなく「描かれたもの」に見せています。マスクは 256px から
フレーム解像度へ拡大されるので、その過程で輪郭が自然に馴染みます。
セグメンタが読めない環境では楕円マスクにフォールバックします。

**変形** (`src/deform.js`)
UV空間の変位フィールド。手の移動量の**符号を反転**して書き込むのがポイントで、
「手の後ろから画素を引っぱってくる」ことで表面が手についてくるように見えます。
シェーダは portrait と ink を同じ `uv'` でサンプリングするため、**インクも一緒に伸びます**。
引き伸ばされた量に応じて僅かに色を薄めており、画像がただ滑るのではなく
素材が耐えかねている感じになります。

**インク** (`src/ink.js`)
胸像が静止しているので、インクレイヤーは**追記専用**です。毎フレーム再構築しないので、
垂れ（run）は「毎フレーム進んだぶんだけ線を足す」だけで軌跡そのものになります。
速度は少しずつ落ち、途中で止まります。飛沫は本体の楕円群＋衛星ドロップで構成され、
手の速度があるときは進行方向に伸びます。

`undo` はインクのキャンバスと変位フィールドをジェスチャー単位でスナップショットして戻します。

## 調整

`src/config.js`。よく触るのは:

- `deformStrength` / `deformRadius` — 壊れ方の強さと範囲。
- `pinchOn` / `pinchOff` — ピンチ感度（手の大きさで正規化済みなので距離に依存しません）。
- `autoShutterFrames` / `countdownSeconds` — 自動シャッターの粘り。
- `inkScale` — インクレイヤーの解像度倍率。下げると軽くなります。
- `palette` — 色。`1`–`9` キーに対応するので9色まで。

会場ではコンソールから `breakToCreate`（`{ CONFIG, tracker, ink, deform, renderer, ui, state, shoot, finish }`）
を触ると再読み込みなしで変えられます。

## 動くための条件

- **WebGL2** 必須（合成と変形がシェーダ側にあるため）。
- カメラは secure context 必須。`localhost` か HTTPS で開いてください。
- 初回に MediaPipe のモデル（約20MB）を CDN から取得します。

会場のネットワークが不安なら同梱できます:

```sh
./scripts/fetch-models.sh
```

`v2/vendor/` に落ちるので、スクリプトが表示する通りに `v2/src/config.js` の5つのパスを
差し替えてください。パスは `config.js` 自身の位置を基準に絶対URL化されるので、
サブディレクトリに置いても壊れません。

## 制限

- 1人ずつの体験です（`numFaces: 1`、切り抜きも1人想定）。
- 切り抜きは selfie segmentation なので、背景と髪の境界や、体の一部が
  フレーム外にあるときは輪郭が甘くなります。
- 変形は変位フィールドなので、大きく引っぱると引き伸ばしのにじみが出ます。
  それを「壊れ」として使う設計ですが、`deformStrength` で抑えられます。
