# BREAK TO CREATE. — 自身の再構築 (Ver.2)

> DESTROY THE OLD SELF. DISCOVER THE NEW YOU.

映し出された自分自身に触れ、壊し、塗り替えることで殻を破り、新たな自分の形を見出す体験。

公開URL: **https://bufeks.github.io/LAB/v2/**
（Ver.1「顔にペイント」はそのまま https://bufeks.github.io/LAB/ にあります）

## 道具はありません

手のかたちが、そのまま道具になります。**手にはインクが付いていて**、
どのポーズを取っているかは常に画面下のガイドが光って教えてくれます。

| | ジェスチャー | 起きること |
| --- | --- | --- |
| **ぶつける** | 手を握って振る | インク玉が飛ぶ。勢いのある向きに飛沫が伸び、当たったところから数本垂れる |
| **塗る** | 人差し指を1本立てる | 指先でなぞったところに絵の具が乗る |
| **ぶちまける** | 手をぱっと開く | バケツ1杯分が落ち、カーテン状に幾筋も流れる |
| **歪ませる** | つまんで引っぱる | 粘土のように顔が引きずられる。乗っているインクも一緒に伸びる |

色と太さは、左と下のパネルに**手をしばらく重ねる**と選べます（枠が満ちたら決定）。
`UNDO` / `RESET` / `DONE` も同じ操作です。

**どれだけ壊しても、目だけは潰れません。** インクは目にかからず、
変形も目のまわりだけは効きません。周囲が壊れるほど、残った目が際立ちます。

## 仕組み

### 顔ローカル空間

すべての鍵は、インクと変形を**画面ではなく頭に固定された座標系**で持つことです。
両目尻から相似変換（原点＝鼻根、回転、スケール＝目尻間距離）を毎フレーム作り、
その 2x3 行列をシェーダに渡します。フラグメントシェーダは画面座標を顔座標に変換してから
インクと変位を引くので、

- 顔が動いても、傾けても、近づいても、塗った跡は顔についてくる
- 垂れは画面の下ではなく**顔を伝って**落ちる
- インクレイヤーは**追記専用**のまま。マークごとの再計算が一切要らない

という3つが同時に成立します。単位は「目尻間距離」なので、ブラシの太さも
カメラからの距離に関係なく顔に対して一定です。

相似変換なので、表情による非剛体の変形や大きく横を向いた場合の追従は近似です。
正面〜±40°くらいが実用範囲です。

### 合成

WebGL2 の1パスで組み立てています。

```
f      = 画面座標 → 顔ローカル座標
d      = 変位フィールド(f)              ← 顔ローカルなので凹みは顔に残る
色     = 紙 と 胸像 を人物マスクで混ぜ、インク(f + d) を上に乗せる
カメラ = 画面座標 + d を画面空間に戻したぶん だけずらしてサンプリング
```

インクとカメラ映像を**同じ変位で**引くので、すでに乗っているインクも一緒に伸びます。
引き伸ばされた量に応じて僅かに色を薄めており、画像がただ滑るのではなく
素材が耐えかねている感じになります。

胸像の見た目は、ImageSegmenter（selfie segmentation）で人物を切り抜き、
輝度をコントラスト強調して紙の色に乗算したものです。セグメンテーションは
負荷が高いので2フレームに1回だけ更新しています（輪郭はそこまで速く動きません）。
読み込めない環境では切り抜きなしで、カメラ映像がそのまま出ます。

### 目のガード

顔ローカル空間で両目の楕円を求め（まばたきで縮まないよう、瞼の開きではなく
目頭〜目尻の幅を基準にしています）、その内側で

- インクのアルファを 0 に落とす
- 変位を 15% まで落とす

を行っています。判定はインクを引くのと**同じ座標**で行うので、表面を引きずったときも
ガードが一緒に動きます。

### ジェスチャー判定

指が伸びているかは「指先が手首から、その指の第2関節より遠いか」で判定します。
スケールにも回転にも依存しません。握り拳も親指と人差し指が近づくため、
つまみは「人差し指が実際に前に伸びていること」を追加条件にしています。

ポーズは**数フレーム続いて初めて切り替わり**ます。手が形を変える途中で
道具が暴れないためです。またポーズごとに作用点が違う（指先／つまみ位置／掌の中心）ので、
ポーズが変わった瞬間に平滑化位置を作用点へ置き直しています。
これをしないと、持ち替えるたびに顔が引っぱられます。

## 調整

`src/config.js`。よく触るのは:

- `gesture.pinchOn` / `pinchOff` — つまみの感度（手の大きさで正規化済み）。
- `gesture.throwSpeed` — どれくらい振ればインクが飛ぶか。
- `gesture.holdFrames` — ポーズが切り替わるまでの粘り。上げると誤爆が減り、反応は鈍る。
- `deformStrength` / `deformRadius` — 壊れ方の強さと範囲（目尻間距離が単位）。
- `eyeGuard` — 目を守る範囲。`deform: 0` にすると目は完全に動かなくなる。
- `dwellMs` — 手をかざしてから決定までの時間。
- `cutoutEveryNFrames` — 上げると軽くなり、輪郭の追従が鈍る。

会場ではコンソールから `breakToCreate`（`{ CONFIG, tracker, face, gestures, ink, deform,
renderer, ui, state, finish, generate }`）を触ると再読み込みなしで変えられます。

## キーボード

体験中: `1`–`6` 色 / `[` `]` 太さ / `z` 戻す / `r` 全部戻す / `g` 生成しなおし /
`Enter` 完成 / `h` UI非表示 / `f` フルスクリーン。完成後は `s` 保存 / `Enter` もう一度。

マウスでも一通り試せます。`b` `i` `p` `o` でマウスに割り当てるポーズを
（歪ませる／ぶつける／塗る／ぶちまける）選び、ドラッグします。

## 動くための条件

- **WebGL2** 必須（合成・変形・目のガードがすべてシェーダ側にあるため）。
- カメラは secure context 必須。`localhost` か HTTPS で開いてください。
- 初回に MediaPipe のモデル（約20MB）を CDN から取得します。

会場のネットワークが不安なら同梱できます:

```sh
./scripts/fetch-models.sh
```

`v2/vendor/` に落ちるので、スクリプトが表示する通りに `v2/src/config.js` の5つのパスを
差し替えてください。パスは `config.js` 自身の位置を基準に絶対URL化されるので、
サブディレクトリに置いても壊れません。

## 制限

- 1人ずつの体験です（`numFaces: 1`）。
- 顔が外れるとインクと変形は表示されません（消えてはおらず、顔が戻れば戻ります）。
- 切り抜きは selfie segmentation なので、髪の境界や、体がフレーム外にあるときは
  輪郭が甘くなります。
- 手を開いた状態でフレームに入ると、その瞬間に1杯ぶちまけます。
  気になる場合は `gesture.holdFrames` を上げてください。
