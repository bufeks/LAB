# BREAK TO CREATE. — 自身の再構築 (Ver.2)

> DESTROY THE OLD SELF. DISCOVER THE NEW YOU.

映し出された自分自身に触れ、壊し、塗り替えることで殻を破り、新たな自分の形を見出す体験。

公開URL: **https://bufeks.github.io/LAB/v2/**
（Ver.1「顔にペイント」はそのまま https://bufeks.github.io/LAB/ にあります）

## 道具はありません

手のかたちが、そのまま道具になります。**手にはインクが付いていて**、
どのポーズを取っているかは常に画面下のガイドが光って教えてくれます。

操作はすべて**2段階**です。まず形をつくって少し止めると、画面の中の手の色が濃くなります
（構えた合図）。**そこから動かして、はじめて効きます。** 形をつくっただけでは何も起きません。
一振りにつき一発なので、手を止めているあいだに絵が壊れていくことはありません。

| | ①構える | ②動かす | 起きること |
| --- | --- | --- | --- |
| **ぶつける** | 手を握る | 振る | 振った1回につきインク玉が1つ。勢いの向きに飛沫が伸びる |
| **塗る** | 人差し指を1本立てる | 振る | 動かしているあいだだけ、指先の跡に絵の具が乗る |
| **ぶちまける** | 手を開く | 叩きつける | 叩いた1回につきバケツ1杯。幾筋も垂れていく |
| **歪ませる** | つまむ | 引っぱる | 粘土のように顔が引きずられる。乗っているインクも一緒に伸びる |
| **潰す** | 両手を開く | 挟み込む | 両手のあいだが押し縮められ、はみ出した分が横に膨らむ |

指の形を変えている最中の手は「構えていない」扱いになります。持ち替えた瞬間に
暴発しないためです。

**つかむ大きさ**は、手をカメラに近づけるほど大きくなります。手の見かけの大きさを
顔の大きさと比べて決めているので、UIを介さずに連続的に効きます（太さの S/M/L が粗い調整、
手の距離が細かい調整）。

「潰す」と「ぶちまける」はどちらも開いた手の動作なので、**両手が互いに近づいているか、
顔に向かっているか**で見分けています。挟んでいるあいだ、その両手はバケツを空けません。

色と太さは、左と下のパネルに**手をしばらく重ねる**と選べます（枠が満ちたら決定）。
`UNDO` / `RESET` / `DONE` も同じ操作です。

**どれだけ壊しても、目だけは潰れません。** ガードは目の開き自体の大きさなので、
**塗りは瞼のきわまで来て**そこで止まります。変形だけは目のまわりを広めに抑えて、
眼窩が潰れないようにしています。

白目と黒目のコントラスト強調は、**目のまわりがインクに埋もれている度合いに比例**して
かかります。何も塗っていなければ目は素のまま（カメラが捉えたそのまま）で、
周囲が塗り潰されるほど立ち上がります。常時かけると、無傷の顔に死んだ patch が
貼りついたように見えました。無彩色化もやめて、色を保ったまま階調だけ立てています。

## 仕組み

### 顔ローカル空間

すべての鍵は、インクと変形を**画面ではなく頭に固定された座標系**で持つことです。
両目尻から相似変換（原点＝鼻根、回転、スケール＝目尻間距離）を毎フレーム作り、
ランドマークは反転済みなので、33（本人の右目）が**画面の右**、263 が画面の左です。
この順で軸を取ることで frame の x が画面の x と同じ向きになり、その垂線が下を向きます。
逆にすると垂れが上に落ちます。
その 2x3 行列をシェーダに渡します。フラグメントシェーダは画面座標を顔座標に変換してから
インクと変位を引くので、

- 顔が動いても、傾けても、近づいても、塗った跡は顔についてくる
- 垂れは画面の下ではなく**顔を伝って**落ちる
- インクレイヤーは**追記専用**のまま。マークごとの再計算が一切要らない

という3つが同時に成立します。単位は「目尻間距離」なので、ブラシの太さも
カメラからの距離に関係なく顔に対して一定です。

相似変換なので、表情による非剛体の変形や大きく横を向いた場合の追従は近似です。
正面〜±40°くらいが実用範囲です。

### 絵の具の質感

目指しているのは、飛沫が散った紙ではなく**顔を覆う厚く濡れた塗膜**です。
そのために4つのことをしています。

**飛沫** — 塊はやわらかいスタンプ、飛沫は硬い小さなスタンプで置きます。ぶつけると
本体は小さく、代わりに**無数の液滴**が飛翔方向に扇状に散ります。粒径はべき分布なので
大半は微細な粒で、たまに太い滴が混じります。速い粒は進行方向に伸びて筋になり、
さらに鞭を振ったような線が数本、途中で途切れながら走ります。
微細な粒はスプライトの減衰で消えてしまうため、一定径以下は実線の円で描いています。

**混色** — マークは着地した場所の色を拾って混ざります。混合は RGB の線形補間ではなく
**濃度空間**で行います。RGB で補間すると黄から青への中点が灰色になってしまい、
絵の具として成立しないためです。濃度で混ぜると黄の上の青はオリーブグリーンになります
（実測 `216,224,0` → `112,120,24`、彩度 32→96）。
参照用に低解像度のスナップショットを数フレームおきに更新しており、
キャンバスの読み戻しでパイプラインを止めることはありません。

**にじみ** — 塗りたてのあいだは数フレームおきに拡散させ、時間とともにその「濡れ」が
減って固まります。細かい飛沫を消さないよう半径は控えめです。

拡散するのは**塗られた範囲だけ**です。当初は1024²全面をぼかしており、計測すると
それがフレーム内の他のすべてを合わせたより高くつく単独の最大コストでした。
（同一負荷での実測: 全面 74ms → 塗られた範囲 50ms。局所的なマークならもっと下がります。）
なお `ctx.filter` 付きの `drawImage` はクリップの大きさでレイヤーを確保するため、
クリップを先に設定しないと領域を絞っても全面ぶんのコストがかかります。

混色が参照する低解像度スナップショットは、**変化があったときだけ**取り直します。
読み戻しは GPU のパイプラインを止めるので、塗り終わって何も動いていない間に
4フレームおきに実行していたのは純粋な無駄でした（固まった状態の `ink.update` は実測 0ms）。

**厚み** — シェーダはインクのアルファ勾配を塗膜の法線として読みます。数テクセル離して
サンプリングしているので、折り目ではなく濡れた縁の広いベベルになります。

**立体** — ここが要です。当初はカメラ映像の輝度勾配を「顔の形」として使っていましたが、
正面から照らされた顔は輝度がほぼ平坦なので、シャツの上では立体的に見えるのに
**顔の上だけ真っ平ら**になっていました。照明に依存する設計そのものが誤りでした。

いまは顔ランドマークの **z 値**から顔ローカル空間の深度マップを作っています。468点を
グリッドに散らし、隙間を埋めて平滑化し、その勾配を法線としてアップロードします。
照明条件に関係なく、鼻筋・眉・頬に沿って塗膜が回り込みます。
映像由来の法線は細部のために弱く混ぜてあります。

**テカリ** — 上の頭部法線と塗膜自身の法線を混ぜ、鋭いグリントと広いシーンの2ローブで
ライティングします。顔料は意図的にクリップ手前に抑えています。明るい色を1.0 超に
押し上げると、ハイライトだけでなく階調まで白飛びして立体が消えるためです。

**透け** — 顔の陰影が顔料を透かして出るので、鼻や唇の立体が塗膜の下に読み取れます。
デカールではなくコーティングに見えるのは主にこの項です。加えて塗膜は肌に僅かに影を落とします。

**垂れ** — 置く場所を決め打ちせず、**塗膜そのものから生えます**。低解像度スナップショットを
走査して「上に十分な絵の具が溜まっていて、下が空いている」画素、つまり塊の下端の輪郭を
探し、そこから発生させます。顎の縁に沿って何本も垂れるのはこのためです。色もその場所の
（すでに混ざった）色をそのまま引き継ぎます。

挙動は、まず玉が膨らんで**溜まり**、そこから離れて**加速**し、運んでいる量を使い切りながら
細くなって**失速**、最後に先端へ雫を残して止まる、という順です。長さは決め打ちではなく
残量で決まるので、絵の具が厚く溜まっているところほど太く長く落ちます。

発生条件は「新しく置かれた絵の具の濡れ」で、垂れ自身が維持する濡れでは発生しません。
これが無いと垂れが垂れを呼び続けて止まらなくなります。

垂れは**顔ローカル空間の下方向**に落ちます。頭を傾ければ垂れも一緒に傾きます。
画面の下へ落とすと塗膜が顔から剥がれてしまうため、この設計です。

**範囲** — インクは人物マスクで切り抜かれ、**身体の上にしか乗りません**。外した分は
背景の紙には落ちず、単に無かったことになります。

ただしセグメンテーションは**手も「人物」と判定します**。そのままだと顔に向けた絵の具が、
手前にかざした自分の手の上に乗ってしまいます。そこで手のランドマークから別途マスクを作り、
塗りの範囲から差し引いています。副次的に挙動も正しくなり、手をかざしているあいだは
その下の塗膜が隠れ、どければ戻ります。

### 合成

WebGL2 の1パスで組み立てています。

```
f      = 画面座標 → 顔ローカル座標
d      = 変位フィールド(f)              ← 顔ローカルなので凹みは顔に残る
色     = 紙 と 胸像 を人物マスクで混ぜ、インク(f + d) を上に乗せる
カメラ = 画面座標 + d を画面空間に戻したぶん だけずらしてサンプリング
```

インクとカメラ映像を**同じ変位で**引くので、すでに乗っているインクも一緒に伸びます。
引き伸ばされた量に応じて僅かに色を薄めており、画像がただ滑るのではなく
素材が耐えかねている感じになります。

胸像の見た目は、ImageSegmenter（selfie segmentation）で人物を切り抜き、
輝度をコントラスト強調して紙の色に乗算したものです。セグメンテーションは
負荷が高いので2フレームに1回だけ更新しています（輪郭はそこまで速く動きません）。
読み込めない環境では切り抜きなしで、カメラ映像がそのまま出ます。

### 目のガード

顔ローカル空間で両目の楕円を求め（まばたきで縮まないよう、瞼の開きではなく
目頭〜目尻の幅を基準にしています）、その内側で

- インクのアルファを 0 に落とす
- 変位を 15% まで落とす

を行っています。判定はインクを引くのと**同じ座標**で行うので、表面を引きずったときも
ガードが一緒に動きます。

### 挟んで潰す

放射状に押す通常の変形とは別の演算子です。両手を結ぶ線の中点に向かって表面を引き寄せ、
同時に直交方向へ押し出します。滑るのではなく**圧縮されて横に逃げる**ように見えるのは
この2つ目の項によるものです。押し込まれた量（両手の距離が縮んだぶん）がそのまま
変形量になります。

### ジェスチャー判定

指が伸びているかは「指先が手首から、その指の第2関節より遠いか」で判定します。
スケールにも回転にも依存しません。握り拳も親指と人差し指が近づくため、
つまみは「人差し指が実際に前に伸びていること」を追加条件にしています。

ポーズは**数フレーム続いて初めて切り替わり**ます。手が形を変える途中で
道具が暴れないためです。またポーズごとに作用点が違う（指先／つまみ位置／掌の中心）ので、
ポーズが変わった瞬間に平滑化位置を作用点へ置き直しています。
これをしないと、持ち替えるたびに顔が引っぱられます。

## 調整

`src/config.js`。よく触るのは:

- `gesture.pinchOn` / `pinchOff` — つまみの感度（手の大きさで正規化済み）。
- `gesture.holdFrames` — ポーズが切り替わるまでの粘り。上げると誤爆が減り、反応は鈍る。
- `gesture.armFrames` — 構えたと見なすまでのフレーム数。上げるとより慎重になる。
- `gesture.speed` — 各アクションが要求する手の速さ（px/フレーム）。上げると発火しにくくなる。
- `gesture.lead` — 投げたインク玉が手のどれだけ先に着弾するか（フレーム単位の移動量）。
- `gesture.crush` — 挟む判定の速さ・距離、圧縮の強さ、横への膨らみ。
- `gesture.handRefSpan` / `handGrab` — つかむ大きさが手の距離でどれだけ変わるか。
- `gesture.cooldown` — 同じ手が続けて発火できるまでの間隔。
- `paint` — `form` 透け、`relief` 縁の厚み、`formRelief` ハイライトの回り込み、`gloss` 濡れ具合。
- `pickup` — 下の色をどれだけ拾うか（混色の強さ）。`0` で混色なし。
- `spatter` — 飛ぶ液滴の数の倍率。
- `speckRadius` — これ以下の粒は実線で描く境目。
- `drip` — `minMass` 垂れ始めるのに必要な絵の具の量、`gravity`/`maxSpeed` 落ちる速さ、
  `hang` 溜まっている時間、`perSeed`/`maxRuns` 本数、`seedWetness` 発生する濡れの下限。
- `bleedEveryNFrames` / `bleedRadius` — にじみの強さ。重い環境では前者を上げる。
- `probeEveryNFrames` — 混色と垂れの発生位置が参照するスナップショットの更新間隔。
- `maskHands` / `handDilate` — 手を塗りの範囲から除く／その余裕。
- `idleResetMs` — 無人になってからリセットするまで。`0` で無効。
- `deformStrength` / `deformRadius` / `deformGain` — 壊れ方の強さと範囲（目尻間距離が単位）。
- `eyeGuard` — `rx`/`ry` 守る範囲（目の幅の倍数）、`punch` 白目と黒目のコントラスト、
  `deformScale` 変形を抑える範囲、`deform: 0` で目は完全に動かなくなる。
- `bodyColour` — `1` で身体はカラー、`0` でモノクロの胸像。
- `inkOnBodyOnly` — `false` にすると背景にもインクが飛ぶ。
- `depthGrid` / `depthRange` / `paint.faceRelief` / `paint.sculpt` — 顔の立体の作り込み。
- `dwellMs` — 手をかざしてから決定までの時間。
- `cutoutEveryNFrames` — 上げると軽くなり、輪郭の追従が鈍る。

会場ではコンソールから `breakToCreate`（`{ CONFIG, tracker, face, gestures, ink, deform,
renderer, ui, state, finish, generate }`）を触ると再読み込みなしで変えられます。

## キーボード

体験中: `1`–`6` 色 / `[` `]` 太さ / `z` 戻す / `r` 全部戻す / `g` 生成しなおし /
`Enter` 完成 / `h` UI非表示 / `f` フルスクリーン。完成後は `s` 保存 / `Enter` もう一度。

マウスでも一通り試せます。`b` `i` `p` `o` でマウスに割り当てるポーズを
（歪ませる／ぶつける／塗る／ぶちまける）選び、ドラッグします。

## 画面サイズ

キャンバス上のツールレールは**短い辺**を基準に組み立て、それでも横幅に収まらなければ
行全体を縮めます。縦向きのカメラだと高さ基準では横にはみ出すためです。
極端に縮んだときは日本語の補助ラベルを落とします。

キャンバスの表示サイズは、上下のUIの高さを決め打ちで引くのをやめ、**残った領域を実測**して
決めています。スマホでは決め打ちの値が常に外れていました。ガイドは折り返し、
横向きでは高さを詰めます。

## 無人設置

体験者がフレームから去って `idleResetMs`（既定12秒）が経つと、作品は自動的に消えて
次の人を待つ状態に戻ります。このとき生成のスウィープは走らせません。誰もいない部屋で
始めて誰もいないまま終わるだけだからです。次の人が顔を映して静止した時点で改めて生成されます。
完成画面も放置されれば体験に戻ります。`0` にすると消えずに残ります。

## 動くための条件

- **WebGL2** 必須（合成・変形・目のガードがすべてシェーダ側にあるため）。
- カメラは secure context 必須。`localhost` か HTTPS で開いてください。
- 初回に MediaPipe のモデル（約20MB）を CDN から取得します。

会場のネットワークが不安なら同梱できます:

```sh
./scripts/fetch-models.sh
```

`v2/vendor/` に落ちるので、スクリプトが表示する通りに `v2/src/config.js` の5つのパスを
差し替えてください。パスは `config.js` 自身の位置を基準に絶対URL化されるので、
サブディレクトリに置いても壊れません。

## 制限

- 1人ずつの体験です（`numFaces: 1`）。
- 顔が外れるとインクと変形は表示されません（消えてはおらず、顔が戻れば戻ります）。
- 切り抜きは selfie segmentation なので、髪の境界や、体がフレーム外にあるときは
  輪郭が甘くなります。
- にじみは1024pxのレイヤー全体をぼかす処理です。非力な端末では
  `bleedEveryNFrames` を上げてください。
- 顔の立体はランドマークの z から作るので照明に依存しませんが、身体（首から下）には
  ランドマークが無く、そこは従来どおり映像の輝度に頼ります。
- インクの切り抜きは selfie segmentation の精度どまりです。髪の生え際や
  手が身体に重なる場面では境界が甘くなります。
