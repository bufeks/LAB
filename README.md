# Face Paint

Webカメラに映った自分の顔に、手でペイントするインスタレーションのデモ。

指でつまむ（親指＋人差し指）と、その位置に絵の具が乗ります。塗った跡は**顔に貼りつき**、
顔を動かしたり傾けたりしても一緒に動きます。ビルド不要の静的サイトで、映像はすべて
ブラウザ内で処理され、外部には送信されません。

**公開URL: https://bufeks.github.io/LAB/**

デフォルトブランチへの push ごとに `.github/workflows/pages.yml` が上記へデプロイします。
リポジトリ設定の Settings → Pages → Build and deployment → Source を
**GitHub Actions** にしておく必要があります（初回のみ）。

## 動かす

そのままブラウザで上のURLを開けば動きます。手元で動かす場合は:

```sh
./scripts/serve.sh          # http://localhost:8000/
```

ブラウザで開いて「カメラを許可して開始」を押すだけ。`file://` では動きません
（getUserMedia とモジュール読み込みに secure context が必要）。`localhost` は
secure context 扱いなので HTTPS は不要です。別マシンから見せる場合は HTTPS で配信してください。

初回は MediaPipe のモデル（約 10MB）を CDN から取得します。

## 操作

| 操作 | 動き |
| --- | --- |
| 親指と人差し指をつまむ | ペイント |
| 画面左の丸をつまむ | 色を選ぶ |
| 画面下のボタンをつまむ | 太さ・ブラシ・消しゴム・左右対称・戻す・全消し |
| マウスのドラッグ | 同じことがマウスでもできる（動作確認用） |

キーボード: `1`–`8` 色 / `[` `]` 太さ / `b` ブラシ切替 / `e` 消しゴム / `m` 左右対称 /
`z` 戻す / `c` 全消し / `s` PNG保存 / `h` UI非表示 / `f` フルスクリーン

インスタレーション設置時は `f` でフルスクリーン、`h` で UI とHUDを消せます。

## 仕組み

MediaPipe Tasks Vision の FaceLandmarker（顔478点）と HandLandmarker（手21点×2）を
`requestAnimationFrame` のループで回しています。ポイントは**塗った跡をどう顔に貼りつけるか**です。

1. 両目尻（landmark 33 / 263）から、頭部の相似変換フレーム（原点・回転・スケール）を作る。
2. 塗った点ごとに、**最も近い顔メッシュ4点**を選び、その4点それぞれからの相対位置を
   このフレームの座標系で記録する（距離の逆二乗で重み付け）。虹彩の点（468番以降）は
   視線で動いてしまうので除外。
3. 毎フレーム、記録した相対位置を現在のランドマークから復元して描き直す。

単純な1枚のアフィン変換だと表情で崩れますが、近傍ランドマークへの重み付き紐付けなら
口を開ける・笑うといった非剛体の変形にも追従します。UV テクスチャ空間を持たずに済むので、
顔メッシュの三角形分割テーブルも不要です。

描画は顔の輪郭（FACE_LANDMARKS_FACE_OVAL）でクリップしているので、はみ出しても顔の中だけに乗ります。
ランドマークと指先の座標にはそれぞれ指数移動平均をかけて、ジッタによる線のブレを抑えています。

### ファイル

| ファイル | 役割 |
| --- | --- |
| `src/config.js` | 調整用のパラメータ全部（しきい値・色・モデルのURL） |
| `src/tracking.js` | MediaPipe の初期化と検出。左右反転もここで吸収 |
| `src/face.js` | 頭部フレーム、顔ローカル座標への変換／逆変換、輪郭パス |
| `src/painter.js` | ストロークの保持と、毎フレームの再描画 |
| `src/hands.js` | ピンチ判定（ヒステリシス付き）とポインタ化 |
| `src/ui.js` | キャンバス上のツールバー。手でもマウスでも同じ当たり判定 |
| `src/main.js` | ループと入力のルーティング |

## 調整

`src/config.js` を見てください。よく触るのは:

- `pinchOn` / `pinchOff` — ピンチの感度。手の大きさで正規化しているのでカメラとの距離には依存しません。
- `brushSizes`, `palette` — 太さと色。パレットは8色を超えるとキーボードの `1`–`9` から溢れます。
- `faceSmoothing` / `handSmoothing` — 上げると滑らかに、下げると追従が速く。
- `idleClearMs` — 顔が一定時間消えたら自動で全消しする（無人設置向け）。既定は `0` で無効。

会場で走らせたまま詰めたいときは、コンソールから `facePaint`（`{ CONFIG, tracker, face,
painter, ui, state }`）を触ると再読み込みなしで値を変えられます。

## オフラインで動かす

会場のネットワークが不安な場合はモデルを同梱できます。

```sh
./scripts/fetch-models.sh
```

`vendor/` に落ちるので、スクリプトが最後に表示する通りに `src/config.js` 冒頭の
4つのパスを差し替えてください（MediaPipe は動的 import なので、書き換えるのは
`config.js` だけです）。

## 制限

- 顔は1人（`numFaces: 1`）。複数人に広げるなら `FaceModel` を人数分に増やし、
  ストロークを顔IDで分ける必要があります。
- 大きく横を向くと、隠れた側のランドマークの推定が甘くなり塗りも歪みます。
  正面〜±40°くらいが実用範囲です。
- ペイントは顔の表面に乗るだけで、鼻の陰などのオクルージョンは考慮していません。
