# EVO — いのちの旅

一つの細胞から銀河の中心まで、生命の進化をたどるブラウザゲーム（Spore にインスパイア）。
ビルド不要の静的サイトで、画像・音声ファイルも使っていません（描画は Canvas、効果音は WebAudio で合成）。

公開URL: **https://bufeks.github.io/LAB/evo/**

手元で動かす場合はリポジトリのルートで `./scripts/serve.sh` を実行し、
http://localhost:8000/evo/ を開いてください（ES Modules なので `file://` では動きません）。

## 5つの段階

| 段階 | 内容 | 次へ進む条件 |
| --- | --- | --- |
| 🦠 細胞期 | 原始のスープを泳ぎ、植物や肉を食べて成長。他の細胞に食べられないように | 成長レベル5 |
| 🦎 クリーチャー期 | 島の7種族と **交流**（相手の求める 歌う/ダンス/魅了/ポーズ をまねる）するか **狩る**。骨から新パーツを発見 | 脳レベル5 |
| 🔥 部族期 | RTS。食料を集めて部族員を増やし、4部族と **贈り物・演奏で同盟** するか **小屋を壊して征服** | 全部族を同盟/征服 |
| 🏙 文明期 | 戦車（占領）・宣教師（信仰）・買収（お金）で惑星のすべての都市を手に入れる | 全都市を支配 |
| 🚀 宇宙期 | 銀河マップをワープ。植民・テラフォーム・船の強化、帝国と交易/同盟/戦争、海賊の撃退 | 銀河の中心に到達 |

**エディタ**（細胞期・クリーチャー期）でパーツを付け、体節を伸ばし、色と模様を決めた姿が
その後のすべての段階（部族員、都市のシンボル、宇宙船のパイロット）に登場します。
パーツの組み合わせで能力（すばやさ・かみつき・歌う…）が決まり、口の種類で食性が決まります。

各段階の遊び方（友好的か攻撃的か）が **特性** として次の段階に引き継がれ、
最後に種族のタイプ（外交官／戦士／放浪者）が決まります。

## 操作

- 細胞期: マウスを押した方向へ泳ぐ / WASD。Space 電撃、Shift 毒（パーツがあれば）、E エディタ
- クリーチャー期: クリックで移動・相手を選択 / WASD。1〜4 攻撃、5〜8 交流、R 仲間にする、E エディタ（巣の近く）
- 部族期・文明期: ドラッグで範囲選択、A で全員、右クリックで命令（タッチはタップ）。矢印キー/ミニマップでカメラ移動
- 宇宙期: 星をクリック → ワープ。ドラッグでスクロール、ホイールでズーム

進行状況はブラウザの localStorage に自動保存されます。タイトル画面から到達済みのステージを選び直せます。
`?stage=tribe` のように URL に付けるとそのステージへ直接飛べます（動作確認用）。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `src/main.js` | ループ、タイトル・ステージ紹介・エンディングなどのつなぎのシーン |
| `src/game.js` | シーン切り替えとセーブの共有オブジェクト |
| `src/creature.js` | 種のデザイン（背骨の体節＋パーツ）、能力計算、描画、ランダム生成 |
| `src/editor.js` | 細胞／クリーチャーエディタ |
| `src/cell.js` / `creatureStage.js` / `tribe.js` / `civ.js` / `space.js` | 各段階 |
| `src/terrain.js` | 陸の段階で共有する島の生成（ノイズ） |
| `src/rts.js` | 部族期・文明期で共有する範囲選択など |
| `src/ui.js`, `input.js`, `audio.js`, `save.js`, `util.js` | HUD・入力・効果音・セーブ・数学 |
